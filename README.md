# AVMarket

Site de catalogue pour du matériel audiovisuel et des composants PC.

## Fonctions

- Catalogue d'annonces
- Plusieurs photos par annonce
- Téléversement de photos
- Liens Vinted et Leboncoin
- Panier de sélection
- Formulaire de réservation
- Administration protégée
- Base H2 locale
- Aucun paiement intégré

mvn spring-boot:run
